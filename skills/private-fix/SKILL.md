# private-fix

Read project instructions and the affected code and callers. Reproduce the reported
behavior with existing tools; add a focused regression test when appropriate.
Name the demonstrated cause, implement the smallest complete fix and run the
project's relevant checks. Do not relax assertions to hide regressions. After two
failed attempts at the same approach, reassess the evidence and change approach.
Report what changed, verification results and remaining uncertainty. Do not
publish learnings, route context to another provider or change project tooling.
