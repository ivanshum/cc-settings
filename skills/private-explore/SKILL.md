# private-explore

Read project instructions, then inspect the smallest relevant set of files.
Trace the entry point, callers, configuration and tests. Treat names in the request
as hypotheses, not conclusions. Do not edit, install, publish or invoke external
services. Exclude secrets and unrelated files. Summarize the behavior with file and
line references; separate verified facts from assumptions and missing evidence.
