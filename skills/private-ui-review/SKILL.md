# private-ui-review

Read approved design references and project restrictions before reviewing.
Inspect desktop, tablet and phone layouts plus narrow-screen overflow. Check
hierarchy, spacing, wrapping, image crops, keyboard navigation, visible focus,
contrast and reduced motion. Keep screenshots and sensitive case content local.
Use the existing design system; do not introduce an unsolicited redesign.
Report reproducible findings and identify unavailable browser or device checks.
A review is read-only; implement changes only when requested.
