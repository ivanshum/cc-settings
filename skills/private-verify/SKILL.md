# private-verify

Identify the promised behavior and the repository's own verification commands.
Inspect scripts before running them; use the established package manager.
Run relevant checks and a realistic behavior test where feasible. For UI changes,
inspect desktop/mobile, keyboard behavior, reduced motion and console errors.
Distinguish implemented, tested, committed, packaged and deployed status.
Never invent metrics, suppress failures, weaken tests or describe untested behavior
as verified. Do not use an external reviewer or upload evidence automatically.
